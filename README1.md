GreenLeaf Plants - E-commerce Website
A modern, responsive e-commerce website for houseplants built with React and Redux.

🌟 Features
Core Functionality
Product Catalog: Browse six unique houseplants across three categories

Shopping Cart: Add, remove, and manage items with real-time updates

Responsive Design: Works seamlessly on desktop and mobile devices

State Management: Efficient state handling with Redux

Pages
Landing Page: Beautiful hero section with company introduction

Product Listing: Categorized plant display with add-to-cart functionality

Shopping Cart: Complete cart management with quantity controls

Shopping Cart Features
Add/remove items with visual feedback

Quantity adjustment (increase/decrease)

Real-time total calculation

Persistent cart state

Disabled buttons for items already in cart

🛠️ Technologies Used
Frontend: React 18.2.0

State Management: Redux, React-Redux

Routing: React Router DOM

Styling: Pure CSS with modern design

Icons: Emoji-based icons for cart

📦 Installation
Prerequisites
Node.js (version 14 or higher)
